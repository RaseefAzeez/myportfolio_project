My Projects

My Portfolio Website

This is a static website hosted on AWS S3 with a contact form connected via API Gateway, Lambda, and DynamoDB. The entire setup uses Infrastructure as Code (IaC) with CloudFormation and features a CI/CD pipeline automated using GitHub Actions.

Architecture Overview

This diagram illustrates the serverless architecture of my portfolio website, featuring static hosting on Amazon S3, a contact form powered by AWS API Gateway and Lambda, data storage in DynamoDB, and real-time notifications via SNS. The entire infrastructure is managed as code using CloudFormation, with CI/CD automation handled by GitHub Actions for seamless deployments and logging via CloudWatch.

Technologies Used

  • AWS Services: S3, API Gateway, Lambda, DynamoDB, SNS, CloudFormation, IAM, CloudWatch
  • CI/CD: GitHub Actions, GitHub workflow
  • Version Control: Git, GitHub
  • Frontend: HTML, Tailwind CSS, JavaScript

Features

  • Static website hosting with high availability.
  • Serverless contact form with data persistence.
  • Real-time email notifications on form submission.
  • Infrastructure as Code (IaC) for consistent deployments.
  • Automated CI/CD pipeline for both frontend and backend.

Future Enhancements

  • Integrate a blog section with content hosted on DynamoDB.
  • Implement a CI/CD pipeline for the blog content.
  • Add a custom domain with Route 53 and CloudFront.
